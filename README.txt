نسخه پایتونی دسکتاپ مانیتور قیمت — ویندوز ۱۱

Python 3.11 یا جدیدتر نصب کنید و run.bat را اجرا کنید.
این فایل در اولین اجرا PySide6 و jdatetime را نصب می‌کند؛ اینترنت لازم است.
اجرای مستقیم پس از نصب وابستگی‌ها: py price_monitor.py

رابط برنامه بومی Qt است و از HTML یا مرورگر استفاده نمی‌کند.
تم پیش‌فرض سفید و آبی است؛ چهار تم از «تغییر تم» انتخاب و ذخیره می‌شوند.
اطلاعات در پوشه LocalAppData\ArazmanPriceMonitor ذخیره می‌شوند.
هنگام خروج و تأیید، یک پشتیبان در زیرپوشه backups ساخته می‌شود.
اطلاعات دموی مرورگر به این نسخه خودکار منتقل نمی‌شوند.
باسلام و اسنپ شاپ طبق توافق هنوز قیمت‌گذاری ندارند.
این نسخه سورس پایتون است، نه نصب‌کننده EXE.

اگر Python 3.14t دارید، نسخه معمولی Python 3.12 64-bit را نیز نصب کنید. فایل اجرا پایتون معمولی را در مسیرهای رایج پیدا می‌کند.

فونت وزیرمتن همراه برنامه است. پوشه fonts را در کنار price_monitor.py قرار دهید.
